# Scale Touch Button in the Inspector

You can change the scale of a touch button from the inspector. To do this:

* Press the button **Show Touch Button Scale**.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FUOhwXAPYfFrtSUtorpgz%2F0?alt=media)

* Select the X and Y scale in the range.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FVTcAKywY6fo0GPGa24Wm%2F1?alt=media)

You can also activate the option **Width = Height**, to set the same value for both sizes.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FvxBUuu2dfV2VhL1e2x9r%2F2?alt=media)
