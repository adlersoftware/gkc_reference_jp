# Diable Touch Buttons on Start

If you want to disable any **Touch Button** at the start of the game, for example for buttons that are only enabled in certain moments (like the button to open a door or use a device), follow these steps:

* Open the list of **Touch Buttons Disabled At Start**.

![
](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2F6M3LrqqeQ8U9oQFS5pPw%2F0?alt=media)

* Press the button **Add Button**.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FDqOBQKNKKky5J1ymZg1Y%2F1?alt=media)

* Select the action whose touch button you want to disable at the start (the list of actions is dynamic according to the axes currently configured).

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FSJyW9QmjPW5U6izI2WMr%2F2?alt=media)
