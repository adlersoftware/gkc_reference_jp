# Interactor

This page covers the integration of Interactor from Negen Games

## What is Interactor?

<figure><img src="https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FtbDmAuXLjgluz3eygqY4%2Fimage.png?alt=media&amp;token=3902d311-b2b0-4103-b9aa-5f748ee41141" alt=""><figcaption></figcaption></figure>

**Interactor** is designed to cover all aspects of any kind of interaction, from the designing stage in the editor to handling complex interactions in runtime.&#x20;

It contains editor tools to simplify the process of preparing a fully interactable environment (Look at the Easy Workflow section below).&#x20;

And in runtime, it handles which player parts are going to interact with which parts of the interacted object, while using its own IK to animate player bones.

{% hint style="info" %}
You can find more information about **Interactor**, and its documentation and also purchase it over on the [Unity Asset Store](https://assetstore.unity.com/packages/tools/animation/interactor-interaction-handler-for-ik-178062).
{% endhint %}
