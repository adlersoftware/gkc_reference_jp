# Tutorial - Configure Random Walk Movement on Attack Mode and Target Spotted on A.I

1. Drag your A.I into the scene.
2. Go to **Other AI Systems**>**AI Behaviour**>**Powers Behavior**
3. Screen up/down to the *AI Fire Weapons System Brain*.
4. Toward the bottom of the script you will see **Random Walk Settings** there you can change the minimum and max wait time, duration and radius.
