# Enable and Disable Certain Parts of the Map

The map can be shown in the map or you can select if a certain floor or map part is not shown, so the player needs to reach that zones or get a map pickup of that zone, to make it visible in the map window.

For this, go to **Map Creator Inspector** and open the **Map Parts List** of a floor.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FB3xviZFW4dw1sn8rjjZx%2F0?alt=media)

Then, you can select every map part state of that floor one by one, using the **Enabled** option.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2F3SvVc3g3ok8BHhWesE24%2F1?alt=media)

You can also, enable or disable entire floors with the options **Disable All Floor Parts** and **Enable All Floor Parts**.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FP5QyZCIrwimUIkIMIWrj%2F2?alt=media)
