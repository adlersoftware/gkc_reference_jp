# Manage Multiple Floors

Go back to the **Floor List** gameObject, to the **Map Creator Inspector**, and press the button **Add Floor** again.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FpDiCh6UCsIiaIzkbbZoX%2F0?alt=media)

Like before, a new floor transform will be added to the hierarchy.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FjmGtaTGHLxRyiJZaWe4n%2F1?alt=media)

Also, in the scene, a gizmo shows the position of every floor, so move the new floor position according to your level scene.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FZ3d4HWv2t2kjdArpUc9S%2F2?alt=media)

This will be used to know where the player is according to the closest vertical distance to the floor list (used by default). Now you can start to add new map parts to the new floor.

For example in this image, there are two floors using two cubes and two map floors configured, so the closest floor map to the player will be rendered in the map window.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FoZiroewzg6uby4Welc7h%2F3?alt=media)

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2F68H6rZdPB5uwRKeVOruj%2F4?alt=media)

With the new floor added to the list, don’t forget to go to the Map System inspector and press Search Floor List.

![](https://3552900959-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-McLLp9jDL-LIuzRrSTQ%2Fuploads%2FyF0NXPRJ2ut33mxbaPdK%2F5?alt=media)
